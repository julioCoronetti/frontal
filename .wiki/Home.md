# Frontal - Terminal Harness

## 1. Visão Geral
O Frontal é uma interface de terminal (TUI) para o Antigravity CLI (`agy`) e motores compatíveis com o protocolo `stream-json`.

O objetivo do projeto é construir um harness rápido, responsivo e determinístico, fornecendo uma experiência de uso simples e de alta performance como a do `agy`, com recursos estruturados de navegação e visualização.
