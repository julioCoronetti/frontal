# Frontal

Terminal user interface (TUI) harness para o Antigravity CLI (`agy`) e motores compatíveis com o protocolo `stream-json`.

## Status do Projeto
O projeto está em processo de reestruturação arquitetural visando máxima performance nativa, simplicidade operacional e baixa latência no consumo e renderização do fluxo de agentes.

O protótipo inicial (Python / Textual) está preservado na branch [`legacy`](https://github.com/julioCoronetti/frontal/tree/legacy) para consulta e reaproveitamento de componentes desacoplados (protocolo, engine e testes).
